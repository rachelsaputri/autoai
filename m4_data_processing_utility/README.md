# M4 Data Processing Utility

This project is a data processing utility written in M4, a macro processor.

## Features
- Data ingestion
- Data transformation
- Data validation
- Report generation

## Usage
1. Run `m4 -I ./macros main.m4` to process the data.
2. Review the output for processed data and reports.

## Structure
- `main.m4`: Main entry point for data processing.
- `macros/`: Directory containing reusable macros.
