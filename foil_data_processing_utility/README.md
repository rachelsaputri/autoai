# FOIL Data Processing Utility

A lightweight data processing engine written in FOIL (Functional Object Interaction Language).

## Features
- Data Ingestion
- Schema Validation
- Transformation Engine
- Report Generation

## Usage
Compile with `foilc main.foil` and run with `./main`.

## Architecture
- `main.foil`: Entry point.
- `ingester.foil`: Handles data loading.
- `transformer.foil`: Applies data rules.
- `reporter.foil`: Generates outputs.
