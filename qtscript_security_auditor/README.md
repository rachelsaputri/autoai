# QtScript Security Configuration Auditor

This tool provides a fully functional security configuration auditor built strictly using QtScript.

## Features
- Reads and validates security configuration files.
- Checks for compliance with predefined security policies.
- Reports discrepancies and potential vulnerabilities.
- Generates detailed audit logs.

## Usage
1. Place your security configuration files in the `configs/` directory.
2. Run the main script `main.qs`.
3. View the audit report generated in `reports/`.

## Dependencies
- QtScript (Qt4/Qt5 embedded scripting engine)
