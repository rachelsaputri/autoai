# Sawzall Data Processing Utility

This utility provides a foundational framework for processing and analyzing data using the Sawzall programming language.
It is designed for high-performance log analysis and data aggregation.

## Features

- **Log Parsing**: Efficiently parses structured and semi-structured log lines.
- **Aggregation**: Performs statistical aggregations on data streams.
- **Extensibility**: Modular design allows for easy addition of custom processing rules.

## Usage

1. Ensure Sawzall is installed in your environment.
2. Run the main script using the Sawzall interpreter:
   ```bash
   sawzall main.szl
   ```

## Structure

- `main.szl`: The primary processing logic.
