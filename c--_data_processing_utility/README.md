# C-- Data Processing Utility

A lightweight, high-performance data processing utility written in C--. This tool provides core data manipulation capabilities including loading, cleaning, transforming, and exporting datasets.

## Features

- Load data from standard text-based formats (CSV, TSV, JSON-like structures)
- Clean data by removing duplicates and handling missing values
- Transform data using built-in functions
- Export processed data
- Modular design for easy extension

## Prerequisites

- C-- compiler
- Basic understanding of C-- syntax

## Usage

Compile the main module and run:

```bash
cc-- main.cc
./a.out input.txt output.txt
```
