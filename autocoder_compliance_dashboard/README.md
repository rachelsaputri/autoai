# Autocoder Compliance Dashboard

## Overview
The `autocoder_compliance_dashboard` is a production-grade, fully functional diagnostic and visualization tool built strictly using the Autocoder programming language. It serves as the analytical frontend for the enterprise compliance ecosystem, designed to ingest, parse, and visualize complex telemetry data generated by the `mesa_compliance_agent_simulator` and processed by the `a0_audit_engine` and `a0_formal_verifier`.

This tool provides real-time monitoring of compliance drift, agent behavioral convergence, and policy elasticity, transforming raw audit logs into actionable, high-fidelity diagnostic reports.

## Features
- **Real-Time Telemetry Parsing**: Ingests raw compliance metrics and agent state data from the simulation environment.
- **Drift Visualization**: Renders visual representations of policy drift and non-compliance events using Autocoder-native control output routines.
- **Agent Convergence Analysis**: Calculates and displays the convergence velocity of security agents toward target compliance states.
- **Diagnostic Report Generation**: Produces structured reports highlighting anomalies, policy elasticity limits, and remediation priorities.
- **Export Capabilities**: Exports structured audit data for downstream processing by the `abset_formal_policy_checker` and other enforcement layers.

## Building
To build the Autocoder project, use the provided Makefile:
```bash
make clean
make all
```

## Execution
Run the compiled binary to start the interactive diagnostic dashboard:
```bash
./compliance_dashboard
```

## Integration
This tool is designed to integrate with the following components:
- **mesa_compliance_agent_simulator**: For ingestion of agent behavioral data.
- **a0_audit_engine**: For parsing audit log structures.
- **a0_formal_verifier**: For correlating simulation results with formal proofs.
