"# KRC Text Formatting and Dataset Cleaning Tool\n\nThis tool is a robust, automated dataset cleaning and text formatting utility written in KRC. It is designed to process structured text datasets (CSV, TSV, Log files) by:\n\n1. **Ingesting** data from various delimiter-separated formats.\n2. **Sanitizing** text fields by removing noise, normalizing whitespace, and standardizing casing.\n3. **Cleaning** numerical and categorical data by handling missing values and type coercion.\n4. **Validating** data integrity against user-defined schema rules.\n5. **Exporting** the cleaned data back to a standardized CSV format.\n\n## Features\n- Modular pipeline architecture (Parse -> Clean -> Validate -> Format).\n- Support for multiple input delimiters.\n- Configurable noise filters and whitespace normalization.\n- Built-in statistical summary generation.\n- Production-ready error handling and logging.\n\n## Usage\nCompile and run the main KRC script:\n\n```bash\nkrc main.krc input_data.csv output_data.csv --delimiter=',' --log-level=INFO\n```\n\n## Modules\n- `main.krc`: Entry point and orchestration.\n- `io_handler.krc`: File reading and writing.\n- `text_sanitizer.krc`: Cleaning and formatting logic.\n- `data_validator.krc`: Schema and constraint validation.\n- `logger.krc`: Centralized logging.\n
