# Squeak Encryption Tool

## Overview
The Squeak Encryption Tool is a modular framework for secure file storage applications built STRICTLY using the Squeak programming language. It leverages Squeak's advanced object persistence capabilities and memory safety features to provide robust encryption and decryption utilities.

## Features
- Modular encryption algorithms
- Secure file storage integration
- Memory-safe operations
- Object persistence support

## Installation
1. Install the Squeak VM
2. Clone this repository
3. Open the package in Squeak
4. Follow the implementation patterns outlined in the documentation
