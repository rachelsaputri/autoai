# G Data Processing Utility

This utility provides a robust and efficient framework for data processing tasks using the G programming language. It supports data ingestion, validation, transformation, and reporting.

## Features
- Data ingestion from various formats
- Data validation with customizable rules
- Data transformation using defined pipelines
- Report generation with detailed metrics

## Getting Started
1. Ensure you have the G compiler installed.
2. Navigate to the `g_data_processing_utility` directory.
3. Run the main program using `g run main.g`.

## Usage
- `main.g`: Entry point for the data processing utility.
- `ingester.g`: Handles data ingestion from input sources.
- `validator.g`: Validates data against defined rules.
- `transformer.g`: Transforms data according to specified logic.
- `reporter.g`: Generates reports with processing metrics.
