# CESIL Compliance Drift Detector

## Description
This tool is a lightweight compliance drift detection system written in Cesil. It monitors system configuration states, compares them against a predefined baseline, and flags deviations.

## Features
- Baseline state comparison
- Drift count calculation
- Alert generation on deviation

## Usage
1. Run the `main.ctl` script.
2. Input the current system state when prompted.
3. Review the output for compliance status.
