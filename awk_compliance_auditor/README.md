# AWK Compliance Auditor

A modular data processing utility written in AWK for compliance auditing and data validation.

## Features
- Data ingestion and parsing
- Policy rule evaluation
- Compliance reporting
- Sanitization of input data

## Usage

```bash
awk -f audit_engine.awk -f policy_rules.awk -f sanitizer.awk -f run_audit.sh input_file.txt
```
