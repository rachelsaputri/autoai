# K Compliance Auditor

A high-performance, fully functional compliance auditing tool built strictly using the K programming language. This system monitors system configurations, validates them against defined security policies, and generates detailed compliance reports.

## Features
- Real-time configuration monitoring
- Policy-based compliance checking
- Detailed reporting and alerting
- Optimized for performance using K's array-oriented processing

## Usage
Compile and run the K scripts:
```bash
k main.k
k auditor.k
k policy_engine.k
k reporter.k
k config_monitor.k
```

## Structure
- `main.k`: Entry point
- `auditor.k`: Core auditing logic
- `policy_engine.k`: Policy evaluation and matching
- `reporter.k`: Report generation
- `config_monitor.k`: System configuration monitoring
