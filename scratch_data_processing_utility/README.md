# Scratch Data Processing Utility

This utility demonstrates data processing concepts (ingestion, transformation, validation, reporting) implemented in Scratch.

Since Scratch is a block-based visual programming language, this project provides:
- A structured breakdown of the data processing logic.
- Block-by-block implementation instructions.
- A simulation script (Python) that mimics the Scratch logic for testing purposes.

## Components

1. **Ingestion**: Reads raw data (CSV/JSON lines).
2. **Validation**: Checks for data integrity.
3. **Transformation**: Cleans and formats data.
4. **Reporting**: Generates summary statistics.

## Scratch Implementation Guide

To create this in Scratch:
1. Create variables: `Data Buffer`, `Record Count`, `Error Count`, `Output Log`.
2. Import the CSV extension.
3. Use lists to hold ingested data.
4. Implement loops to validate and transform each item.
5. Use the `Pen` extension to visualize the data distribution.
