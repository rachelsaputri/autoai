# EPL Compliance Report Generator

An autonomous compliance report generator built strictly using Enterprise Programming Language (EPL). This tool ingests remediation logs, calculates aggregate compliance metrics, formats outputs according to regulatory schemas, and persists audit trails.

## Features
- Deterministic report generation engine
- Aggregate compliance metric calculation
- Regulatory schema formatting
- Strict memory management
- Structured data serialization
- Explicit buffer handling for large datasets
- Transaction safety for report commits
- Deterministic state transitions for report versioning
- Comprehensive logging for traceability

## Usage
Compile the EPL source files and run the main executable to start the report generation process.

## Integration
Designed to integrate with the Phrogram remediation pipeline.
