# RuneScript Data Processing Utility

A lightweight data processing utility written in RuneScript.

## Features

- Ingest data
- Validate records
- Transform data
- Export results

## Usage

```rune
run main.rs
```

## Components

- `main.rs`: Entry point
- `parser.rs`: Data parsing
- `validator.rs`: Validation logic
- `transformer.rs`: Data transformation
- `reporter.rs`: Report generation
