# Factor Complex Data Extraction and Parsing Utility

A robust, multi-format data extraction and parsing utility written in the Factor programming language.

## Features
- **Multi-format Support**: Parses CSV, TSV, and JSON data.
- **Sanitization**: Cleans strings and handles malformed entries.
- **Statistical Analysis**: Computes mean, median, and mode for numeric columns.
- **Type Inference**: Attempts to infer numeric types for analysis.

## Prerequisites
- Factor language installed.
- Factor `io` and `json` vocabularies.
