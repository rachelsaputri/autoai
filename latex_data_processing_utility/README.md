# LaTeX Data Processing Utility

This is a data processing utility written in LaTeX. It demonstrates data ingestion, transformation, and reporting capabilities using LaTeX's powerful macro and package ecosystem.

## Features
- Data Ingestion
- Data Transformation
- Data Reporting
- Configuration Management

## Usage
1. Configure `config.cfg` with your data source settings.
2. Run `main.tex` to process the data.
3. View the generated report in `output.pdf`.

## Requirements
- LaTeX distribution (e.g., TeX Live, MiKTeX)
- Required packages: `xstring`, `pgffor`, `array`, `datatool`
