# App Inventor Compliance Auditor

This project implements a Mobile Compliance and Device Security Auditor using App Inventor for Android's visual block language.

## Features

- **Runtime Permission Auditing**: Checks for critical permissions and their status.
- **Secure Local Storage Validation**: Ensures data is stored securely on the device.
- **Network Traffic Inspection**: Inspects network traffic for Android components.
- **Automated Compliance Scoring**: Generates a compliance score based on the audit.

## Project Structure

- `appinventor_compliance_auditor.aia`: The main project file containing all blocks and screens.
- `appinventor_compliance_auditor.aiproj`: The project manifest.
- `README.md`: This file.

## How to Use

1. Open the `appinventor_compliance_auditor.aia` file in the App Inventor editor.
2. Review the blocks and screens to understand the functionality.
3. Build the APK or use the App Inventor Companion to test the application on an Android device.
