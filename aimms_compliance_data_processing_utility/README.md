# AIMMS Compliance Data Processing Utility

This project implements a robust, fully functional data processing utility using the AIMMS language. It is designed for compliance-oriented data pipelines, featuring rigorous validation, transformation, and reporting capabilities.

## Features
- **Ingestion**: Processes JSON and CSV formatted data inputs.
- **Validation**: Enforces strict schema and data type checks.
- **Transformation**: Normalizes data formats and applies compliance rules.
- **Reporting**: Generates detailed validation and processing logs.

## Structure
- `aimms_compliance_data_processing_utility.app.xml`: Project manifest and configuration.
- `aimms_compliance_data_processing_utility.inc`: Core include file containing all procedural logic.
