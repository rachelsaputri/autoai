# Rebol Data Processing Pipeline

A modular, lightweight data processing utility written in REBOL. Designed for efficient parsing, transformation, and filtering of data streams.

## Features
- JSON and Text data parsing
- Modular filter pipeline
- Configurable output formats
- Lightweight and fast

## Usage

```bash
rebol rebol_data_processing_pipeline/processor.r
```

## Structure
- `processor.r` - Main entry point and core logic
- `config.reb` - Configuration defaults
- `filters/` - Modular filter functions
