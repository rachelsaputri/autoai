# Euler Low-Level Memory and Network Protocol Simulator

A low-level simulator built in the Euler programming language to model memory management operations and network protocol behaviors. 

## Features
- **Memory Allocator**: Simulates heap memory allocation and deallocation with custom memory pools.
- **Protocol Engine**: Simulates a simplified TCP-like reliable data transfer protocol.
- **Packet Simulator**: Models packet headers, payloads, and retransmission logic.
- **Network Topology**: Basic host-to-host communication with configurable bandwidth and latency.

## Usage
Run the simulator via the Euler interpreter:
```bash
euler main.e
```
