# Data Viz Toolkit

A high-performance data visualization library written in Rust.

## Features
- Utilizes `plotters` for efficient 2D rendering.
- Supports line charts and bar charts.
- Designed for zero-cost abstractions to handle large-scale data streams.
- Easy integration with other Rust-based data processing tools.

## Installation

Add the following to your `Cargo.toml`:

```toml
[dependencies]
data_viz_toolkit = { path = "./data_viz_toolkit" }
```
