# Low-Level Memory Network Simulator

A functional simulator for low-level memory management and network protocols written in MIIS.

## Features

- **Memory Manager**: Simulates memory allocation, deallocation, and fragmentation.
- **Protocol Engine**: Simulates packet transmission, routing, and collision detection.
- **Simulator Core**: Orchestrates memory and network interactions.

## Usage

Run the simulator using the MIIS interpreter:

```bash
miis main.miis
```
