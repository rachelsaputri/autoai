# MSL Compliance Verification Framework

## Overview
A fully functional, production-ready compliance verification framework built strictly using MSL (Modular System Language). This framework automates the validation of system configurations against predefined security policies, tracks compliance status across multiple targets, and generates detailed audit reports.

## Features
- **Policy Loading**: Parses CSV-formatted policy files with support for custom rule types, severities, and activation states.
- **Multi-Domain Verification**: Checks authentication, encryption, access control, logging, and backup policies.
- **Real-Time Scoring**: Assigns severity levels and tracks compliant vs. non-compliant states per policy.
- **Automated Reporting**: Generates structured compliance reports with summaries and detailed policy-by-policy breakdowns.
- **Modular Architecture**: Easily extensible with new policy check modules without modifying core logic.
- **Audit Logging**: Maintains a persistent `compliance_engine.log` for all execution events and verification steps.

## Prerequisites
- MSL Runtime Environment v2.1+
- POSIX-compliant file system access
- Admin privileges for reading target system configurations

## Installation & Setup
1. Copy `main.msl` to your MSL execution environment.
2. Prepare a policy file (`policies.csv`) in CSV format:
   ```csv
   1,Password Complexity,Authentication,8,true
   2,TLS Enforcement,Encryption,9,true
   3,Least Privilege,Access,7,true
   4,Audit Logging,Logging,6,true
   5,Daily Backups,Backup,5,true
   ```
3. Run the verifier:
   ```bash
   msl_runner main.msl
   ```

## Usage
The framework automatically loads policies, verifies a default target (`server-01-prod`), and outputs a compliance report to `/compliance_reports/report_01.msl`. All steps are logged to `compliance_engine.log`.

## Extensibility
To add new policy domains, implement a new `check_<domain>_policies` function and register it in the `verify_target` loop. The framework automatically captures and includes results in the final report.
