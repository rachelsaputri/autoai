# Logo Data Processing Utility

A modular data processing toolkit written in Logo, designed for data cleaning, transformation, validation, and reporting.

## Features

- **Data Ingestion**: Load data from text sources.
- **Validation**: Check for data integrity and schema compliance.
- **Transformation**: Clean and normalize data fields.
- **Exporting**: Output processed data in structured formats.

## File Structure

- `logo_data_processing_utility.lgo`: Main entry point.
- `data_ingestor.lgo`: Logic for loading data.
- `data_transformer.lgo`: Logic for cleaning and transforming data.
- `data_validator.lgo`: Logic for validating data rules.
- `data_exporter.lgo`: Logic for exporting results.

## Usage

1. Load the main script: `logo logo_data_processing_utility.lgo`
2. Call specific functions as needed, e.g., `RUNTRANSFORMER`.
