# Io Data Processing Utility

A modular, high-performance data processing utility written in the **Io** programming language.

## Features
- **Data Ingestion**: Reads data from CSV, JSON, and custom delimited files.
- **Transformation**: Supports filtering, mapping, and column selection.
- **Validation**: Checks for schema compliance and data types.
- **Export**: Outputs processed data to JSON or CSV formats.

## Prerequisites
- [Io Programming Language](http://iolanguage.org/)
