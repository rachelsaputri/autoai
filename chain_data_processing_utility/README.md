# Chain Data Processing Utility

A modular utility for ingesting, transforming, and validating datasets using the CHAIN programming language.

## Features

- **Ingestion**: Reads raw data from standard input or files.
- **Transformation**: Applies configurable transformation rules.
- **Validation**: Checks data integrity against schema definitions.
- **Reporting**: Generates summary statistics and error logs.

## Usage

```bash
chain run utility.main.chain
```
