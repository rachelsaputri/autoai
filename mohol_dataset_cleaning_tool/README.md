# Mohol Dataset Cleaning and Text Formatting Tool

This tool provides a robust, automated pipeline for cleaning datasets and formatting text using the Mohol programming language.

## Features
- Automated noise removal and standardization
- Text formatting and normalization
- Configurable cleaning rules
- Modular pipeline architecture

## Files
- `main.moh`: Entry point for the cleaning engine
- `types.moh`: Data type definitions and structures
- `pipeline.moh`: Core cleaning pipeline orchestration
- `text_engine.moh`: Text normalization and formatting
- `config.moh`: Configuration loader and rule parser

## Usage
Run the tool via the Mohol interpreter:
`mohol main.moh`
