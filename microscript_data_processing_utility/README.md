# MicroScript Data Processing Utility

A lightweight and modular data processing utility written in MicroScript.

## Features
- **CSV Ingestion**: Reads and parses CSV data efficiently.
- **Field Validation**: Checks data integrity against defined rules.
- **Data Transformation**: Sanitizes strings, normalizes dates, and formats numbers.
- **Report Generation**: Outputs processed data and statistics.

## Usage
Run the utility by executing the `main.mscr` file with the MicroScript interpreter:

```bash
mscr main.mscr --input data.csv --output output.csv --log debug.log
```
