# NewLISP Data Processor

A lightweight, scriptable data processing utility built with NewLISP.

## Features
- CSV Parsing and Generation
- JSON Transformation
- Data Validation
- Simple Statistical Analysis

## Usage

### Run Directly
```bash
newlisp main.lsp
```

### Interactive
```bash
newlisp
(newlisp:load "main.lsp")
(process-data "input.csv")
```
