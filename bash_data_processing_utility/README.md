# Bash Data Processing Utility

This directory contains a set of modular bash scripts designed to automate common data processing tasks.

## Features

- **Ingestion**: Raw data loading from CSV/TSV files.
- **Transformation**: Field cleaning, type conversion, and formatting.
- **Validation**: Schema checking and duplicate detection.
- **Export**: Structured output generation.

## Usage

Ensure the file has executable permissions:

```bash
chmod +x bash_data_processing_pipeline.sh
```

Run the pipeline:

```bash
./bash_data_processing_pipeline.sh input.csv
```
