# Orc Cryptographic Toolkit

This project implements a complex mathematical and cryptographic algorithm using the Orc programming language. It features a custom implementation of the Elliptic Curve Digital Signature Algorithm (ECDSA) over a finite field, including point addition, doubling, scalar multiplication, and signature verification.

## Features
- ECDSA Point Addition
- ECDSA Point Doubling
- Scalar Multiplication
- Signature Generation and Verification
- Comprehensive Test Suite

## Usage
Compile and run the Orc code to generate keys, sign messages, and verify signatures.
