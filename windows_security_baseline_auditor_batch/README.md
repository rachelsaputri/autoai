# Windows Security Baseline Auditor

## Overview
This tool is a production-grade, fully functional Batch-based Windows Security Baseline Auditor. It is designed to reside in a dedicated folder named `windows_security_baseline_auditor_batch` and contains all necessary implementation files to audit, enforce, and report on Windows security configurations.

## Features
- **Registry Compliance Checker**: Verifies critical registry keys against security best practices using `reg query`.
- **Service Policy Enforcer**: Checks and reports on critical service configurations (Start Type) using `sc query` and `sc qc`.
- **Master Orchestrator**: Coordinates execution, logging, and report generation.
- **Compliance Scoring**: Calculates a compliance score based on passed/failed checks.
- **Structured Reporting**: Generates HTML reports and detailed text logs.
- **Robust Error Handling**: Utilizes `ERRORLEVEL` and proper variable escaping.
- **Self-Contained**: No external dependencies; uses standard Windows commands.

## Prerequisites
- Windows OS (Legacy or Modern)
- Administrative Privileges (Recommended for accurate registry/service checks)
- Command Prompt or PowerShell (to execute `.bat` files)

## Usage
1. Open a Command Prompt with Administrative privileges.
2. Navigate to the `windows_security_baseline_auditor_batch` directory.
3. Run the master orchestrator:
   ```cmd
   auditor.bat
   ```
4. Review the `audit_log.txt` for detailed logs and `compliance_report.html` for a summarized report.

## Security Notes
- **Registry Checks**: Some registry keys may require specific permissions to query. Run as Administrator.
- **Service Checks**: Service status can change dynamically. Checks focus on Start Type configuration.
- **Baseline**: The tool uses hardcoded baselines based on CIS and Microsoft security best practices. Modify `registry_checker.bat` and `service_enforcer.bat` to customize checks.
