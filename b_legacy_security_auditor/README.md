# B Legacy System Security Auditor

This project implements a production-grade Legacy System Security Auditor using the B programming language.

## Features

- Low-level memory inspection and strict type checking for legacy executables.
- Vulnerability pattern matching against historical CVE databases.
- Compliance status evaluation.
- Structured report generation.
- Robust error handling and deterministic execution.
- High-fidelity audit trails.

## Usage

1. Compile the B source files using a B compiler.
2. Run the auditor against target legacy systems.
3. Review the generated compliance reports.

## Project Structure

- `auditor.b`: Main auditor logic and orchestration.
- `config.b`: Configuration parser and management.
- `reporter.b`: Report generation and formatting.
- `README.md`: This file.
