# Ioke Data Processing Utility

This project provides a robust, fully functional data processing utility implemented in **Ioke**, a dynamic programming language for metaprogramming and concurrency.

## Features
- **Data Ingestion**: Reads data from JSON and CSV sources.
- **Validation**: Validates schemas and data types using Ioke's powerful message-passing syntax.
- **Transformation**: Maps, filters, and transforms data records.
- **Reporting**: Generates summary reports of processing activities.

## Requirements
- Ioke VM

## Usage
Run the main entry point to process a dataset:
```bash
ioke main.ik
```
