"# ECC Elliptic Curve Cryptography Toolkit\n\nThis folder contains a Magik implementation of Elliptic Curve Cryptography primitives for secure key exchange and signing.\n\n## Features\n- Point arithmetic on elliptic curves\n- Modular exponentiation\n- SHA-256 hash function\n- ECDSA-style signing and verification\n\n## Usage\n```magik\nrequire 'ecc_ecdsa.mag'\n\n# Define curve parameters\ndefine _sys.ecdsa_secp256k1 := _create_curve(\n  'secp256k1', 0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFEFFFFFC2F,\n  0, 7\n)\n\n# Generate a key pair\nprivkey := _generate_private_key(_sys.ecdsa_secp256k1)\npubkey := _public_key(privkey, _sys.ecdsa_secp256k1)\n\n# Sign a message\nmessage := 'Hello, World!'\nsignature := _sign(message, privkey, _sys.ecdsa_secp256k1)\n\n# Verify signature\nif _verify(message, signature, pubkey, _sys.ecdsa_secp256k1)\n  _print('Signature is valid.')\nelse\n  _print('Invalid signature.')\nend\n```\n\n## License\nMIT
