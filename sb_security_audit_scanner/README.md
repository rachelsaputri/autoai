# SB Security Audit Scanner

## Overview
The SB Security Audit Scanner is a lightweight, Small Basic-based tool designed to perform rapid security audits on local file systems and configurations. It focuses on file integrity, configuration compliance, permission analysis, and automated vulnerability reporting.

## Features
- **File Integrity Verification**: Computes checksums and detects unauthorized changes.
- **Configuration Compliance**: Validates settings against baseline standards.
- **Permission Analysis**: Audits file and folder permissions for security risks.
- **Automated Vulnerability Reporting**: Generates structured reports of findings.

## Installation
1. Clone this repository or download the source files.
2. Ensure you have a Small Basic interpreter to run the tool.

## Usage
Execute the main Small Basic script:
```sb
' Run Main.sb in your Small Basic IDE or interpreter
```

## Output
Reports are saved in the `sb_security_audit_scanner/reports/` directory.
