# Combined Data Processor

A utility for data processing written in Combined Programming Language (CPL).
This tool processes input data according to defined schemas and outputs cleaned, structured results.

## Usage

1. Ensure you have the CPL environment set up.
2. Place your input data files in the `input` directory.
3. Run the processor using the `main.cpl` file.
4. Check the `output` directory for processed results.

## Features
- Data validation
- Schema enforcement
- Error handling
- Configurable processing pipelines
