# MDL Data Processing Utility

This is a complete, functional data processing utility implemented in MDL (Model Definition Language). It provides a robust framework for data ingestion, transformation, validation, and reporting.

## Features
- Data Ingestion from standard sources
- Data Transformation using configurable rules
- Data Validation with comprehensive error handling
- Reporting of processing results

## Usage
Run the utility using the MDL compiler/interpreter:

```bash
ddl compile mdl_data_processing_utility
```
