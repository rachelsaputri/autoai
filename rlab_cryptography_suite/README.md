# Elliptic Curve Cryptography Suite

## Overview
This tool implements a functional Elliptic Curve Cryptography (ECC) suite in Rlab. It provides the core mathematical operations required for secure communications, including:
- Point Addition
- Scalar Multiplication
- ECDSA (Elliptic Curve Digital Signature Algorithm) for signing and verification

## Usage
To use the suite, include the main file in your Rlab environment:
```
include "ecc_suite.rlab"
```

Or use the interactive function:
```
run_ecc_demo()
```
