# AutoIt Data Processing Utility

A comprehensive, production-ready data processing utility built with AutoIt.

## Features

- **CSV Data Processing**: Read, parse, validate, and export CSV files.
- **JSON Data Processing**: Parse and transform JSON data structures.
- **Text Sanitization**: Clean and normalize text data.
- **Statistics Calculation**: Compute basic statistical measures.
- **Data Export**: Export processed data to CSV or JSON formats.

## Requirements

- AutoIt v3.3.14.5 or later
- No external libraries required (uses native AutoIt functions)

## Usage

1. Ensure AutoIt is installed on your system.
2. Run the main script: `main.au3`
3. Configure the settings in the `config.ini` file if needed.
4. Place input data files in the `input` directory.
5. Processed data will be available in the `output` directory.

## Configuration

Edit the `config.ini` file to customize paths and processing options.
