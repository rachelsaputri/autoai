# Data Processing Utility (AutoHotkey)

A robust, production-ready AutoHotkey utility designed for efficient local data processing tasks. This tool focuses on data sanitization, transformation, and reporting without external dependencies.

## Features
- **Data Sanitization**: Cleans up malformed records, handles missing values, and trims whitespace.
- **CSV/Text Processing**: Reads and writes CSV and plain text files.
- **Transformation Engine**: Applies custom rules to transform data types and formats.
- **Reporting**: Generates summary reports with statistics (row counts, error rates, etc.).

## Requirements
- AutoHotkey v1.1 or AutoHotkey v2.x (compatible syntax)
- No external DLLs or libraries required.

## Usage
1. Copy the `main.ahk` file to your desired directory.
2. Ensure `input_data.csv` exists in the same directory (or update the config).
3. Run `main.ahk`.
4. Check `output_data.csv` and `processing_report.txt` for results.
