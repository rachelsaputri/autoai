# s1_security_awareness_simulator

## Overview
This is a production-grade interactive cybersecurity threat modeling and security awareness education platform built STRICTLY using Scratch. It provides organizations with an immersive, block-based environment to simulate real-world attack vectors, visualize dependency chains, and train personnel through interactive compliance workflows.

## Features
- Interactive Threat Scenario Simulations: Users can drag-and-drop threat actors into network diagrams to observe cascading failures.
- Attack Surface Dependency Visualization: Dynamic flowcharts map how a single vulnerability impacts broader system integrity.
- Compliance Workflow Tutorials: Step-by-step guided modules for ISO 27001, NIST, and GDPR compliance checklists.
- Progress Tracking & Reporting: Generates structured completion reports highlighting user proficiency across modules.

## Setup & Usage
1. Open `security_simulator.sb3` in the Scratch desktop editor or online IDE.
2. Click the green flag to initialize the threat intelligence database and user progression states.
3. Navigate the dashboard to select training modules or simulation scenarios.
4. Interact with actors and assets to trigger security events and observe remediation outcomes.
5. Export progress reports to track training milestones.

## Architecture
- Blocks are structured using Scratch's native event-driven programming model.
- Lists store user progress, threat data, and compliance checkpoints.
- Custom blocks encapsulate complex security logic for modularity.
- Variables manage simulation states, score tracking, and scenario parameters.

## Security & Compliance
- Designed for educational and internal training use only.
- Does not execute external commands or access live network interfaces.
- Aligns with OWASP Top 10 visualization standards.
