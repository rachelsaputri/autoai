# Rapira Data Processor

A modular data processing utility written in Rapira.

## Features

- Data ingestion
- Transformation
- Validation
- Output generation

## Usage

Run the main processor:

```bash
rapira main.rap
```

## Structure

- `main.rap`: Entry point
- `parser.rap`: Data parsing logic
- `transformer.rap`: Transformation logic
- `validator.rap`: Validation logic
- `output.rap`: Output generation
