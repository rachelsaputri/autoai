# PL/I Data Processing Utility

This repository contains a data processing utility written in PL/I.

## Purpose
This utility is designed to handle basic data ingestion, validation, transformation, and reporting tasks.

## Components
- `main.pli`: Entry point for the application.
- `processor.pli`: Core data processing logic.
- `validator.pli`: Data validation rules.
- `reporter.pli`: Report generation logic.

## Requirements
- PL/I Compiler
- Standard Library

## Usage
Compile the files using your preferred PL/I compiler and run the executable.

Example:
```bash
pl1 main.pli processor.pli validator.pli reporter.pli
```
