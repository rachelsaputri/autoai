# ABSET Formal Policy Checker

## Overview
`abset_formal_policy_checker` is a production-grade, fully functional formal policy specification and consistency checking framework. It leverages the **ABSET** language to provide set-theoretic policy modeling, automated consistency analysis against logical contradictions, rule dependency mapping, and structured verification reports.

## Features
- **Set-Theoretic Policy Modeling**: Define policies using abstract set operations.
- **Automated Consistency Analysis**: Detect logical contradictions and overlapping rules.
- **Rule Dependency Mapping**: Visualize and analyze dependencies between policies.
- **Structured Verification Reports**: Generate comprehensive reports on policy health and consistency.

## Usage
1. Navigate to the `abset_formal_policy_checker` directory.
2. Run the main execution script.
3. Provide input policy files in the `policies/` directory.
4. Review the generated verification reports in the `reports/` directory.

## Installation
- Ensure ABSET runtime is installed and configured.
- Clone the repository and install dependencies if necessary.
