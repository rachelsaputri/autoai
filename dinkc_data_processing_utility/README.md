# DinkC Data Processing Utility

A modular data processing utility written in DinkC for the Dink Smallwood RPG modding engine.

This tool provides a framework for parsing, transforming, and reporting on data structures commonly used in RPG scripts, including:
- Entity property parsing
- Dialogue node transformation
- Map script execution logic
- Automated reporting of processing results

## Features
- Modular architecture for easy extension
- Script-based configuration
- Standard DinkC API compliance
- Logging and reporting capabilities

## Usage
Compile with `dmk` (Dink Make) or manually include as a script module.
