# Data Processing Utility

A lightweight, modular data processing utility written in **K**. 

It provides capabilities for:
- Loading data from various formats (CSV, JSON, Text)
- Filtering records based on dynamic rules
- Transforming data fields using custom logic
- Aggregating results
- Exporting processed data

## Usage

1. Clone the repository.
2. Open the `main.k` file in a K development environment.
3. Execute the script to run the default demonstration pipeline.

## Components

- `main.k`: Entry point and orchestration logic.
- `loader.k`: Data ingestion from files.
- `transformer.k`: Data cleaning and field transformation.
- `aggregator.k`: Group-by and summary statistics.
- `exporter.k`: Output generation (JSON/CSV).

## Dependencies

- K Language Interpreter
