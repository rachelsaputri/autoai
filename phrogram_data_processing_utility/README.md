# Phrogram Data Processing Utility

## Overview
This utility provides a robust framework for data processing using Phrogram. It handles ingestion, validation, transformation, and reporting of data records.

## Features
- Modular architecture for easy extension.
- Built-in data validation and sanitization.
- Efficient data transformation engine.
- Console-based reporting.

## Usage
Compile the project using the Phrogram compiler:
`phrcc main.phrogram`

Run the application:
`./main`
