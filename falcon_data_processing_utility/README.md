# Falcon Data Processing Utility

A comprehensive, production-ready data processing utility written in the Falcon programming language.

## Features
- Data Ingestion (CSV, JSON)
- Data Transformation (Validation, Cleaning, Formatting)
- Data Export (CSV, JSON)
- Modular Pipeline Architecture

## Prerequisites
- Falcon interpreter (https://falcon-lang.org/)

## Usage
Run the main processor:
```bash
falcon main.fal
```
