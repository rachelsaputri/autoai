### Kojo Data Processing Utility

A complete, functional data processing utility built in Kojo. 

#### Features
- **Ingestion**: Reads data from various sources (simulated via in-memory lists or strings).
- **Validation**: Checks data integrity, types, and formats.
- **Transformation**: Applies mapping, filtering, and normalization logic.
- **Reporting**: Generates summary reports and exports results.

#### Usage
1. Save the `main.kojo` file in a folder.
2. Open Kojo IDE.
3. Open the file.
4. Click 'Run'.

#### Dependencies
- Kojo (Open-Source Educational Tool for Java)
- No external libraries required.
