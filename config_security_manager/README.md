# Config Security Manager

## Overview
Config Security Manager is a tool built in Seed7 for encrypting sensitive configuration data and managing secure distribution to authorized nodes. It supports key rotation, multiple encryption standards, and secure key storage.

## Features
- Encrypts sensitive configuration fields
- Supports AES-256-GCM and ChaCha20-Poly1305
- Manages key rotation and expiration
- Secure key storage with file-based keyring
- Distribution mechanism for authorized nodes

## Usage
Build and run the tool using the Seed7 compiler.

## Dependencies
- Seed7 3.22 or higher
- Crypto libraries (available through Seed7 packages)
